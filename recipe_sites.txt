# savr default site list for multi-site scraping.
#
#   python -m app.cli scrape-sites                          # every site below
#   python -m app.cli scrape-sites --list                   # show what would run
#   python -m app.cli scrape-sites --only allrecipes.com,seriouseats.com --per-site 20
#   python -m app.cli scrape-sites my_sites.txt             # your own list
#
# Format: one start URL per line. A start URL can be a homepage, a category or
# listing page, a sitemap (.xml), or a single recipe. A bare domain
# ("allrecipes.com") means its homepage. "#" starts a comment. Lines for the same
# site share that site's budget (--per-site recipes, --max-pages-per-site pages).
#
# Only recipes that publish schema.org ratings at or above --min-rating (default 4.0)
# with at least --min-reviews (default 5) are kept, so sites without reader ratings
# add little. The scraper obeys robots.txt (sites that block it show as "blocked")
# and waits between requests to each site. Check each site's terms before scraping,
# and comment out any site you don't want.
